
# Fruit and Vegetable Classification 🍎🥦

## Project Overview
This project uses Transfer Learning and a fine-tuned Vision Transformer (ViT) model to classify fruit and vegetable images.

## Problem Statement
The objective is to develop a deep learning application that identifies fruits and vegetables from uploaded images.

## Model
- Architecture: Vision Transformer (ViT)
- Technique: Transfer Learning
- Framework: PyTorch and Hugging Face Transformers

## Hugging Face Model
https://huggingface.co/Qamber-Dashti/fruit-vegetable-classification

## Dataset
Fruit and Vegetable Image Classification Dataset.

## Technologies Used
- Python
- PyTorch
- Hugging Face Transformers
- Streamlit
- GitHub

## Application Features
- Upload fruit or vegetable images.
- Predict the image category.
- Display prediction confidence scores.

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
